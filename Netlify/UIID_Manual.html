🌍 1. UIID란 무엇인가

UIID(Universal Information Identification)는 세계 정보 식별 코드로, 누가·언제·어떤 AI와 함께·어떤 자료를 만들었는지를 하나의 코드에 담은 복합 정보 식별 체계입니다.

기존 UUID가 단순한 무작위 숫자인 것과 달리, UIID는 자료의 출처·생성시점·AI 기여도·내용 지문을 모두 포함합니다.

💛 UIID(세계정보식별코드)는 AI의 진실응답 운동을 위하여 무상 제공됩니다.
👤
User UIID
사람·조직을 식별하는 회원 코드. 1인 1개 기본 발급.
📄
Works UIID
자료·작품마다 부여되는 식별 코드. 제한 없이 등록 가능.

🏷 3. 생성주체 코드
코드의미설명

※ OHO는 AI를 뜻합니다. 현재는 인간이 대신 등록하지만, 가까운 미래에 AI가 직접 자율 등록하는 날을 준비하는 상징적 코드입니다.
👤 4. User_UIID_Account 사용법
회원가입
이름(또는 필명), 생성주체, User Code(4~8자 영문+숫자), 이메일, 비밀번호, 국가를 입력합니다.
User Code는 UIID에 영구적으로 사용되는 나만의 코드예요. 신중하게 정하세요.
회원가입 버튼 클릭 → 이메일 인증 링크 클릭 → 로그인!
로그인 후 회원 UIID가 자동 발급됩니다.
로그인 후 화면

User Code를 클릭하면 회원 UIID가 표시됩니다. P 버튼을 누르면 비밀 메모를 작성할 수 있습니다. UUID 보기 버튼으로 내부 UUID를 확인할 수 있습니다.

예약된 코드

GOOGLE00, MICROSOFT 등 유명 기관명과 00000000~50000000, FFFFFFFF 등 일부 코드는 예약되어 있습니다. 필요한 경우 선등록 신청을 통해 사용할 수 있습니다.

📋 5. Works_UIID_Manager 사용법

자료·작품마다 Works UIID를 생성하고 관리하는 앱입니다.

UIID 생성 순서
생성주체, Creator USER ID, Creator AI ID, 언어/국가, 파일 유형, 검증 상태를 선택합니다.
제목을 입력합니다. 공동저자가 있으면 숫자를 입력해 공동저자 정보를 추가합니다.
미리보기에서 생성될 UIID를 확인합니다. 해시값은 저장 시점에 고정됩니다.
✦ UIID Save 버튼으로 저장합니다. 로컬과 클라우드 DB에 동시 저장됩니다.
주요 기능
기능설명
Copy생성된 UIID 복사
Reset입력 초기화 (새 해시 생성)
Check UIID중복 여부 확인
🔒 자물쇠비밀번호 세션 잠금
P 버튼비밀 메모 (비밀번호 확인 후)
🌐 RegistryRegistry 페이지로 이동
🌐 6. UIID_Registry 사용법

등록된 모든 UIID를 검색하고 열람하는 세계 Registry입니다.

탭 구성
탭설명
📄 WORKS UIID자료·작품 UIID 검색. 생성주체, 언어, 유형, 검증 상태로 필터링 가능.
👤 USER UIID등록된 사용자 UIID 목록. 이름, User Code, UIID로 검색 가능.
✦ 등록Registry에서 직접 UIID 등록 가능.
카드 기능

각 카드에서 공동저자 확인(C버튼), V 검증 정보 확인, P 비밀메모, 지문코드 복사가 가능합니다.

5초마다 자동 갱신되며, Manager에서 저장 시 즉시 반영됩니다.

✦ 7. 선등록 신청

기본 1개 외에 추가 UIID가 필요한 경우 선등록 신청을 할 수 있습니다.

신청 방법
User_UIID_Account 하단의 ✦ 선등록 신청하기 버튼 클릭
표 형식에 조직/대표자명, 신청 User Code, 국가, 이메일, 신청 사유 입력
대규모 신청(10명 이상)은 CSV 다운로드 후 작성하여 이메일로 제출
심사 후 승인 시 이메일로 안내
